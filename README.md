# Supervised course recording

A portable, evidence-led procedure for capturing legitimately accessible course videos with OBS, reviewing the result and tracking what remains. This repository contains **instructions and synthetic examples only**. It does not contain courses, credentials, browser sessions, recordings, transcripts or a running recorder.

Start with [the skill](skills/supervised-course-recording/SKILL.md). A future agent should adapt it to the actual platform and obtain the owner's current authorization before operating a browser, OBS or external account. The private state for a specific learner belongs in a separate private store.

The procedure was distilled from repeated supervised Windows/Brave/OBS captures. Its gates are observed operating safeguards, not a claim that it works unattended on every site. No DRM bypass or recording without permission is supported. Some sites may forbid recording under their terms; check before use.
