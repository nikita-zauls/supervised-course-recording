# Publication boundary

This is a fresh, reviewed documentation export. It is separate from any experimental course-capture application and from the owner's live course-state repository.

Included: an agent skill, capture/quality/state references and one synthetic state example. Excluded: real course identifiers, local paths, purchased content, recordings, subtitles, signed URLs, secrets, authentication/session state, OBS configuration and personal logs. No prior Git history is copied.

Before each public push, enumerate staged files, scan both the worktree and reachable commits for private data, review the exact diff, then confirm the remote owner and visibility. A private repository is not permission to move the excluded media or credentials there either.

This repository has not been tested as an autonomous recorder. The skill can guide a human-supervised agent, but the platform adapter, audio route, OBS source and export settings require fresh local verification. No license is included pending an owner decision.
