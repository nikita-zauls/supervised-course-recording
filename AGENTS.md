# Agent instructions

Read `README.md`, then `skills/supervised-course-recording/SKILL.md`. Treat the skill as a procedure, not permission to operate a browser or start a recording. Confirm legitimate access and the owner's current operation/destination authority.

Keep real course titles, account identifiers, personal paths, signed player URLs, recordings, transcripts, cookies, OBS credentials, live manifests and failure logs out of this public repository and its history. Use synthetic examples. Do not copy files from a private source tree wholesale. A private state file may point to this procedure but must remain separate.

A successful OBS session is not a validated video. Preserve raw captures, verify the full export, distinguish a blocked lesson from a duplicate, and report uncertainty. Stop capture on stalls or mismatched elapsed time rather than recording dead time. Never alter unrelated OBS scenes, camera or microphone settings.
